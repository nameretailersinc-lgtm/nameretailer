## Observed facts (quick recon, 2026-09-30)

Source: unauthenticated fetch of `robots.txt`, `sitemap_index.xml`, child sitemaps, `/`, `/about/`, `/compress-image/`, `/da40toda50/`, `/products/`.

### Business

- **What it is:** a guest-post / link-building marketplace. Homepage title: "Buy Guest Posts on High Authority Sites | Name Retailer". Meta description claims "56,000+ vetted domains by DA, DR, traffic and price".
- **Entity name on /about/:** "Name Retailer Inc" (also written "Retailer Inc" on the same page). Address, country and founding year are not stated on the pages fetched so far.
- **Offer:**
  1. Marketplace listing table. Each row has domain URL, niche, language, country, DA, DR, traffic, spam score, link count/type (e.g. "02 DoFollow links"), turnaround time (TAT) and price in USD. Filters: price, DA, DR, traffic, spam score, language (~24), link type, country (~60).
  2. Content services: content writing, content marketing, SEO-optimized blog posts, social media promotion, proofreading, plagiarism checking.
  3. About 27 free tools. Most run in the browser: image convert/compress/resize/crop/rotate/B&W, text case, word counter, base64, hex→rgb, px→rem, length/temperature/file-size converters. Some imply external data: competitor backlink analyzer, bulk DR checker, keyword suggestion, "high-authority backlink generator", AMP validator, schema validator/generator, OG/Twitter card generators, image alt checker, keyword density.
- **Purchase flow:** the "Buy Post" button links to `/my-account/` and opens a modal, so login is required. WooCommerce handles cart, checkout and accounts. Only one product URL was seen: `/product/link-purchase/`, probably a single generic checkout product.
- **Social:** Facebook page `https://www.facebook.com/profile.php?id=61577321699205`. No other profiles were found in the homepage HTML.
- **Tracking:** Meta Pixel via PixelYourSite (2 pixel IDs present) and Google Site Kit. No GA4 ID was visible in the static HTML.

### Current stack

WordPress 7.1.2, Hello Elementor theme with Elementor Pro 4.2.3, WooCommerce, Rank Math SEO (sitemaps and schema), WP Rocket, Smush, Contact Form 7, Site Kit, PixelYourSite, and a custom plugin `Plugin-1.31/custom-filters` that powers the listing table and filters.

### URL inventory (from sitemaps)

- `post-sitemap.xml`: 19 URLs (blog at `/blog/`; posts use root-level slugs such as `/how-to-buy-links/`)
- `page-sitemap.xml`: 113 URLs
- `category-sitemap.xml`: 1 URL (`/category/uncategorized/`)
- No product sitemap (`/product-sitemap.xml` returns 404)
- **All URLs use trailing slashes.** The new site should keep them (`trailingSlash: true`) so migration doesn't create redirect chains.

Page groups seen: marketplace segment pages (by DA, DR, TF, traffic, price, backlinks, monthly/permanent), about 45 in total; tool pages (~27); service pages; support/legal pages; community pages; blog posts.

### Preliminary issues (to be confirmed by Agent 1's full audit)

- Tool pages have **two H1s** (e.g. `/compress-image/`).
- Junk or duplicate posts are indexed: `/hello-world/`, `/test-blog-post/`, `/2824-2/`, and a `-2` duplicate of `/guest-post-sites-by-domain-rating-why-dr-matters-link-building/`.
- Every post is in "Uncategorized".
- Segment pages overlap and likely cannibalize each other, e.g. `trust-flow-10-to-50` vs `guest-posts-by-majestic-tf-10-to-50`, `trust-flow-above-50` vs `trust-flow-50-and-above`, and `50k-to-500k` vs `100k-to-500k` vs `backlinks-100k-to-500k`.
- A mega-menu of about 50 links is repeated in the page body on every page, and one item appears twice ("Bulk Domain Rating (DR) Checker Tool").
- About 60 listing rows are rendered on each segment page. The same rows appear to repeat across pages, so the content is near-duplicate.
