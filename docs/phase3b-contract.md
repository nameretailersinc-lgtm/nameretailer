## Data and semantics

`lib/commerce/types.ts` is the shared client-safe contract. Products are separate MongoDB `commerce_products`, not generic CMS records. Price is integer cents, USD per owner default. `domain` is a normalized HTTPS publisher URL, preserving meaningful safe paths, not an internal indexable product route. Canonical hosts lowercase and omit leading www; path case is preserved. `externalId` is the legacy export ID (nullable on manual records). `status`: draft/active/archived; imports default draft until reviewed. IDs and canonical full publisher URLs unique; optimistic `version` for updates. No permanent deletions through this slice.

CSV `Price` is placement-only USD. Live storefront purchase-plugin inspection confirms `Article_Price`, `_2`, `_3` are optional 500-, 750- and 1,000-word writing add-on charges, respectively; total is placement plus the selected tier, and zero tiers are unavailable rather than free. Placement-only buyers provide an article. Evidence: [live-commerce-pricing-review.md](live-commerce-pricing-review.md). Preserve those amounts, Title/Description/Keywords, both link-type columns and original metrics in private source fields; future checkout must normalize and validate each product's amounts on the server, never trust client prices. Export `date_added` is invalid on all rows and is not a publication/measurement date. Imported-at timestamps are real system dates. Imported metrics are owner-provided, not independently verified or fresh; legacy zero means unknown until owner clarifies, retain raw zeros privately but use null/unavailable in normalized metrics. Missing turnaround/link-type information says Unavailable, not guaranteed. Do not copy promotional CSV descriptions into SEO pages or imply domains are vetted.

Exclude the exact repeated-header placeholder record. Report nonpositive prices, malformed domains/metrics and canonical duplicate IDs/URLs. Repeated hostnames with distinct meaningful paths are reported, not silently collapsed. Validation precedes writes; no silently choosing among duplicate URL records. Imports are insert-only, never silently overwrite manually edited products. Stage a batch hidden behind its private import marker, then atomically make it visible. Public queries exclude drafts, private source data and import provenance. No individual product pages.

## APIs supplied by root

- `GET /api/products/`: active products only. Query: `q`, `country`, `language`, `category`, `minDr`, `minDa`, `maxPrice` (decimal USD), `sort=domain|priceAsc|priceDesc|drDesc|trafficDesc`, `page`, `pageSize` (max 50). Response `{ data: PublicProduct[], total, page, pageSize }`.
- `GET /api/products/facets/`: `{data: ProductFacets}` from active inventory.
- `GET /api/admin/products/`: same filters plus `status`, page size up to 50; `{data: Product[], total, page, pageSize}`. Admin-only; full source not returned in list.
- `POST /api/admin/products/`: validated ProductInput, admin CSRF/origin required; `{data: Product}`.
- `PATCH /api/admin/products/[id]/`: ProductInput + `version`; optimistic conflict 409. Admin-only.
- `POST /api/admin/products/import/`: multipart CSV `file`, `action=preview|commit`, `sha256` required commit. Max 32 MiB / 100,000 rows. Preview returns `{data:{rows,valid,skipped,errors,warnings,fatal,issueCounts,issues,sha256,sample}}`, max 100 issues and five normalized sample records. Commit defaults draft and refuses errors unless the admin explicitly sets `acceptValidRows=true` to quarantine invalid rows and stage only validated records; the UI must show excluded counts and require an explicit checkbox. Fatal structural errors cannot be bypassed by that checkbox. No raw CSV upload stored in web artifact; private source rows only in MongoDB. Application body limit differs from 2MB generic JSON. Import-only insert semantics and atomic visible-batch marker.
